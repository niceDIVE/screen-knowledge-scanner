2. **位移估计两项增强**（作者已接受）：
   - `WindowsCapture.Gray` 缩略图宽度 160 → **320**（或按窗口尺寸自适应，保证每行 ≥6px），并用**真实小字号截图**对比 160/320 的估计成功率，把数据写进 PR 描述；

3. **失活状态语义**：目标失活（鼠标移出选区 / 前台窗口切换）当前落 `failed`，与真实执行错误同状态。改为 `needs-review` 或独立 `aborted`，note 保留原因（现文案"阅读窗口或鼠标位置发生变化，已停止采集"可沿用）。
