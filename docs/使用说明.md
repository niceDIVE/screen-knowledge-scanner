# 屏幕采集工作台 V2

Windows 发布包解压后，双击 `start.cmd`。新安装默认在 `%LOCALAPPDATA%\Screen\data` 保存知识库和原始图片。启动窗口会显示实际数据目录。如果程序旁已有旧版 `data\knowledge.db`，默认继续使用该目录。

1. 新建一个主题批次，例如“世界书配置笔记”。
2. 导入 PNG/JPEG 截图，或者在 Windows 桌面版框选阅读区域后采集屏幕。
3. 图片会先保存，文字在后台识别。可以继续导入，或切到“识别任务”查看进度、失败原因和重试。
4. 在“原始证据”中逐帧对照图片校对文字。保存校对会保留旧版本，并更新检索和整理正文。
5. 用顶部搜索框检索中文或英文关键词，点击结果打开对应原图。
6. “导出 Markdown”会下载 ZIP，包含 `scan.md`、所有截图和带修订记录的 `manifest.json`。解压后可放入 Obsidian，图片链接使用相对路径。

结束批次后不会再接收新截图，仍可识别、校对和导出；下一段内容创建新批次。

## Windows 屏幕采集

目标：Windows 10 2004 或更新版本、Windows 11，正常登录的桌面会话。默认使用系统 Windows OCR；中文识别需要在 Windows 设置中安装相应语言的文字识别组件。

- `Ctrl+Alt+R`：框选阅读区域。拖动后松开保存，Esc 取消。
- `Ctrl+Alt+S`：立即采集当前画面。
- `Ctrl+Alt+W`：开始一段滚动采集。
- `Ctrl+Alt+Q`：停止滚动采集。

页面“截取屏幕”默认倒计时 3 秒，“滚动采集”会等待 4 秒。请在等待结束前切换到阅读窗口，并把鼠标放在前台窗口和采集区域内。单帧截图校验取图前后的窗口与鼠标，发现变化时取消本次保存。滚动前先保存首帧，默认每步滚一格、间隔 700ms，最多 12 步或 3 分钟。前台窗口、窗口位置或鼠标区域变化时，自动停止并保留已保存的原图。

画面重叠无法确认时，系统会停止并给出核对提示。动画、固定标题和重复排版可能触发该提示；确认位置后，可以继续采集。已保存的原图不会因去重而删除。整理正文只合并能够确认的连续文字重叠；不确定的部分完整保留，并提示核对。

可在 `appsettings.json` 的 `Scanner` 下设置 `CaptureFocusDelayMs`（默认 3000，允许 0–10000）和 `ScrollStabilityWaitMs`（默认 2000，允许 200–5000）。前者控制页面截图倒计时，热键仍立即截图。后者控制滚动采集每次取图等待画面稳定的时间，画面提前稳定便立即继续。

若系统提示热键已占用，可使用页面按钮。日志显示在启动窗口。

滚动状态含义：`running` 采集中；`cancelling` 正在停止；`stopped` 用户按停止；`completed` 达到步数或连续两步画面未移动；`needs-review` 画面重叠无法确认（含缩略图未见位移但原图有变化），需人工核对；`aborted` 前台窗口或鼠标位置变化导致中止（可恢复，不是故障）；`failed` 执行异常。

四组热键可在 `appsettings.json` 的 `Scanner:HotkeyKeys` 改键（`Capture` / `Scroll` / `Stop` / `Region`），格式如 `Ctrl+Alt+S`，支持 Ctrl/Alt/Shift/Win + A-Z/0-9/F1-F24；注册失败时日志给出具体按键、动作与改键路径。

## OCR 选项

发布包的 `appsettings.json` 中，`Scanner:OcrEngine` 支持：

- `auto`：Windows 桌面构建使用 Windows OCR；通用构建使用 Tesseract。
- `windows`：Windows 系统 OCR。
- `tesseract`：需自行安装 Tesseract 和语言模型；例如 `TesseractLanguages` 配置 `chi_sim+eng`。
- `umi`：连接已启动的 Umi-OCR HTTP 服务，默认 `http://127.0.0.1:1224/api/ocr`。

识别失败会明确标为失败，原图保留。安装语言包或修改 OCR 配置后重启服务，再重试对应帧。

## 保存与备份

截图原件按 SHA-256 共享存储，同一图片再次导入仍会产生独立的采集记录。OCR 和人工校对的历次结果都保存在数据库中。整理正文是派生结果，可以重新生成。

V1 整理入库按文本哈希跳过重复内容。V2 保留每次观察的顺序和证据，重复导入时可在原始证据里看到多条帧记录。采集同一主题的后续内容继续使用打开的批次，切换主题或结束批次后再新建。

备份或换目录升级前，先关闭程序并复制整个数据目录。新安装使用 `%LOCALAPPDATA%\Screen\data` 时，升级程序可直接复用。使用旧版随包目录时，可将整个 `data/` 复制到新版程序旁，或设置 `Scanner__DataDirectory` 指向原目录。显式设置的数据路径优先。ZIP 导出适合阅读和交换，数据库恢复入口仍待实现。

V2 暂缓接入 V1 的可选视觉 LLM 二次转写。代码、JSON 或复杂排版继续以原图和人工校对为准，保持默认流程在本机运行，并避免把生成式改写直接写入证据文本。向量 RAG、UI Automation 文字提取和旧版 vault 自动迁移也未纳入本轮。Linux/macOS 通用构建支持导入、OCR、校对、检索和导出，屏幕采集与热键由 Windows 桌面构建提供。
